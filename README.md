# Team NAK Video Engine

A programmatic explainer video: every frame, sound and voice line is generated by Python code, with no editor and no stock footage.

## How it works

| File | What it does |
|---|---|
| `tl.py` | Script lines and timeline. Edit `LINES` to change the narration; all scene timing adapts automatically. |
| `tts.py` | Voiceover with [Kokoro](https://github.com/thewh1teagle/kokoro-onnx), an open-source TTS (voice `am_michael`). Writes `v0.wav`..`v8.wav` and `tts.json`. |
| `mix.py` | Synthesized music, sound effects, voice ducking, loudness, and `mouth.npy` for lip-sync. |
| `render.py` | Skia renderer: the character, 9 scenes, glow, camera, particles and subtitles. Streams frames to FFmpeg. |
| `build.sh` | Runs the whole pipeline and outputs the website and Fiverr versions. |

## Requirements

Python 3.10+ and FFmpeg, then:

```bash
pip install -r requirements.txt
```

`build.sh` downloads the Kokoro voice model and the Montserrat heading font on the first run. Copy the DejaVu fonts from your system (on Linux, `/usr/share/fonts/truetype/dejavu`) into `fonts/dejavu`.

## Build

```bash
./build.sh          # N=8 ./build.sh to use 8 CPU cores
```

This produces `teamnak-explainer-website.mp4` and `teamnak-explainer-fiverr.mp4`. The Fiverr version re-renders only the last segment without the website URL.

## Preview single frames (fast)

```bash
FD=$(pwd)/fonts/ python3 render.py still 2.3 27 55   # saves still_<seconds>.png
```

## Use your own voice

Record each line of `LINES` in `tl.py` as `v0.wav` ... `v8.wav` (one file per line, any sample rate), then create `tts.json` as `{"sr": 48000, "d": [duration_of_each_file_in_seconds, ...]}` and run `./build.sh`. Scene timing and lip-sync follow your recording.

## Brand tokens (`render.py`)

Green `#22C55E`, background `#090E0C`, panel `#101915`, text `#F2F5F3`, muted `#8B9A92`. Fonts: Montserrat ExtraBold (headings), DejaVu Sans / Mono (body, code).
