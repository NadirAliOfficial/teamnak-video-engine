Team NAK

Video, built entirely by code

A 60-second explainer where every frame, sound effect and voice line is generated by Python. No editor, no stock footage.

View the code Download MP4

Script drives everything

Edit the narration lines in tl.py and all scene timing adapts automatically.

Open-source voice

Voiceover with Kokoro TTS, or drop in your own recordings and the lip-sync follows.

Synthesized audio

Music, sound effects, voice ducking and loudness are all generated and mixed in code.

Skia renderer

Character, nine scenes, glow, camera moves, particles and subtitles, streamed to FFmpeg.

Build it yourself

git clone https://github.com/NadirAliOfficial/teamnak-video-engine.git
cd teamnak-video-engine
pip install -r requirements.txt
./build.sh

Needs Python 3.10+ and FFmpeg. The first run downloads the voice model and heading font.
